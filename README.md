# Cursor Free VIP

这是一个用于学习和研究的工具，目前 repo 没有违反任何法律。请支持原作者。

## 功能特点

* 支持 Windows、macOS 和 Linux 系统
* 重置 Cursor 的配置
* 多语言支持（英文、简体中文、繁體中文、越南语）

## 系统支持

| 操作系统 | 架构 | 支持 |
|----------|------|-------|
| Windows  | x64, x86 | ✅ |
| macOS    | Intel, Apple Silicon | ✅ |
| Linux    | x64, x86, ARM64 | ✅ |

## 注意事项

* 请使用管理员身份运行脚本
* 请确保在运行脚本前已经关闭 Cursor
